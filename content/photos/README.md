# 城市照片外链

每座城市一个 `<城市slug>.txt`，**一行一个图片地址**，批量贴 URL 就行，不用改任何代码。

城市的 slug 见 `src/data/photos.ts`（如深圳是 `shenzhen`、杭州是 `hangzhou`）。
例如新建 `shenzhen.txt`：

```
# 以 # 开头的行、空行都会被忽略，可以拿来分组或写备注
https://你的R2域名/sz-01.jpg
https://你的R2域名/sz-02.jpg
https://你的R2域名/sz-03.jpg | 深圳湾的傍晚      # 用 | 在后面加自定义图说
```

要点：

- 不写 `| 图说` 时，自动配「城市 · 序号」作为图说。
- 这些 `.txt` 只存文字链接，**图片本身在图床（如 Cloudflare R2），不进仓库**，所以仓库永远很小。
- 也可以继续用本地文件夹 `src/assets/photos/<slug>/`（少量、压缩过的图）；两种来源会自动合并，本地图在前。
- 上传图床前记得先压缩到网页尺寸（宽 ~1600px、webp、200~400KB）。
